# Final Art Assets

This folder contains first-pass final PNG assets sliced from generated source sheets.

Generated by:

```powershell
python Tools\postprocess_art_assets.py --manifest Assets\Specs\art_asset_manifest.csv --generated-dir Assets\Generated\BatchSheets --final-dir Assets\Final --contact-sheet Assets\Final\contact_sheet_v01.png
python Tools\create_art_previews.py
```

Important files:

- `contact_sheet_v01.png`: all final assets in one review sheet.
- `ContactSheets/`: per-source-sheet review images.
- `TilePreviews/`: 4x4 previews for tile and wall resources.

All assets are versioned as `v01` and should be treated as usable placeholders or first-pass art, not final hand-polished release art.
