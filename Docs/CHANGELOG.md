# 开发版本变更记录

此页区分代码变更与验收范围，不代表正式发布或完整可玩性验收。版本以[build.txt](../build.txt)为准。

## 0.1.3（2026-10-22）

- 修复灵潮怪满血时客户端当前生命偏低：真实消息23复现90满血收到45/90，额外AI现追加当前生命并完整校验。活动组件17→21字节，双方需更新；不改变事件存档。见[第312轮验收](SPIRIT_TIDE_LIFE_2026-10-22.md)。
- 构建/打包/专服、39项源码、7,720项Gameplay及34,530项注册原生通过；其中18个场景使用官方NPC消息解码器，不代表真实双客户端或完整事件通关。

## 0.1.2（2026-10-22）

- 天劫及环境雷击预警线增加一次空间提示音，控制重复/迟到播放并隔离专服音频。见[第311轮验收](WARNING_AUDIO_2026-10-22.md)。

- 同步修复灵织、玄炉守御和雷行九件护甲的新实例装备槽，原生套装收益/代价与拆件清理通过。见[第310轮验收](ARMOR_INSTANCES_2026-10-22.md)。

- 修复两翼、两面具与剑魂时装在新物品实例中丢失装备槽；克隆与存档重载保持正式槽位。见[第309轮验收](RARE_EQUIPMENT_SLOTS_2026-10-22.md)。

- 天劫来源会话由服务器单独同步，支持状态变化广播及迟加入补发。未收到会话时敌对弹幕无伤，已知旧会话在退役、死亡、进入世界及玩家槽位替换后不能重新激活。资源快照与存档布局保持。见[第303轮验收](TRIBULATION_EPOCHS_2026-10-22.md)。
- 修复雷沼云海环境预警误绑定个人天劫、非渡劫时无法释放落雷的问题。保留36帧预警、30伤害及区域冷却。见[第304轮验收](AMBIENT_WARNING_SOURCE_2026-10-22.md)。
- 联机必须双方使用同一构建：新增消息14；不提供旧包兼容读取或已经实测的旧版本握手保证。
- 0.1.2阶段最终检查：39项源码检查、7,720项编译产物Gameplay断言、34,466项注册原生检查及构建/打包/专服装载通过。捕获套接字和直接钩子不证明真实双客户端运输、图形显示、完整通关或平衡。
