# 八种钓鱼匣库存右键原生验收

第315轮（2026-10-22），推进R25。未改游戏规则，版本保持0.1.3。

## 已验证

在加载的官方引擎中给注册玩家设置库存和鼠标右键标志，直接执行正式ItemSlot.RightClick（InventoryItem上下文）。不再将资格、发奖励与消耗分开手动模拟。八种实际钓鱼匣各验证三种场景：空背包叠放2个、最后1个、其余库存填满石块且叠放2个，共24次开启。

每次核对只消耗1个，最后一个清空为空物品；真实世界物品池恰好出现4–8灵石与2–4对应材料、两类/两个奖励实体。紧接着保持引擎设置的冷却和释放状态，再执行一次右键，确认同一帧没有再次消费或追加奖励。此检查不声称持续按住并推进冷却后永远不会再开。

另对五种有进度门槛的匣子，在世界四个门槛全未满足时走同一ItemSlot入口。没有产出奖励；库存与鼠标物品合计仍2个，允许原生右键分拆/移动到鼠标，不能将移动误当作消费。16种资格组合与原物品/Clone/ItemIO重载由[第314轮](FISHING_CRATES_NATIVE_2026-10-22.md)继续覆盖。

新增83项原生，完整35,165项、39项源码、7,720项Gameplay及构建/打包/专服装载通过。[分组断言及包/报告哈希](Evidence/CrateInventory_2026-10-22.json)。恢复玩家、鼠标物品引用、点击/冷却标志、配方候选数组/数量/焦点、世界进度与随机数；清理本轮奖励，不写回来源世界。

## 边界

输入来自夹具设置，不是物理鼠标或渲染界面。引擎仍是专服进程，声音/显示没有真实输出，也未执行完整输入循环、落地拾取、满世界物品容量或真实客户端运输。满背包场景证明奖励实体产生，不证明拾取后的空间处理。锁定匣只通过四门槛全未满足的库存入口；其它组合通过正式资格入口检查。

R25真实鱼池/钓获、经济、旧世界完整主线与多人仍未完成；此轮补齐的是资格—右键—扣一件—真实奖励的原生库存路径。
