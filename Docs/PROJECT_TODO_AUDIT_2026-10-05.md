项目已有 8 个生态定义、12 个 Boss、17 种普通敌怪、5 个友好 NPC、9 个制作站，以及灵气、境界、天劫、声望、配方和基础引导。当前主要缺口是已有内容的真实功能、多人权威与同步、原版进度绑定、职业装备链和终局闭环。应先补完这些，再增加 Boss 数量。

检查覆盖 Common、Content 各内容类别、Localization、Tools、项目入口与配置、README、Docs、Wiki 的机制及进度规格。采用静态代码审查、跨文件引用检索、基础验证，并查看 Calamity 公开仓库结构和部分实现；没有逐像素验收所有美术，也没有完成单人通关或多人实机测试。下列“确认”指代码可直接证明的缺口；“待验证”指需要运行复现；“建议”指可选择的产品扩展，不是现存故障。

本次验证：`verify_localization_keys.py`、`verify_png_assets.py`（1242 个 PNG）、`verify_content_contract.py` 通过。使用桌面捆绑 Python 执行；系统 PATH 的 Python 指向 WindowsApps 别名。`dotnet` 不在 PATH，构建未完成；未运行服务器、客户端、世界生成 smoke test。未执行会重新生成内容的 freshness 脚本，避免审查时改写游戏源码。
