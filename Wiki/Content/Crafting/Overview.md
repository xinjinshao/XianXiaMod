## 制作体系

XianXia 的制作体系围绕 Terraria 原版材料和 Mod 新材料共同展开，避免完全独立的资源孤岛。

## 制作站

| 制作站 | 阶段 | 来源 | 用途 |
| --- | --- | --- | --- |
| 土炉 | Pre-Boss | 基础材料制作 | 低阶丹药 |
| 简易符案 | Pre-Boss | 木材、残符纸 | 符箓 |
| 青木丹炉 | Pre-Hardmode | 药宗守园人 | 中阶炼丹 |
| 旧炼器台 | Pre-Hardmode | 玄炉铁傀 | 胚器和法宝 |
| 星纹丹鼎 | Hardmode | 星渊胎主 | 星灾丹药 |
| 雷纹锻台 | Hardmode | 雷泽蛟 | 雷系装备 |
| 宗门试炼台 | Post-Plantera | 万宗遗址 | 职业分化装备 |
| 天火炉 | Post-Golem | 天碑守御 | 天道系装备 |
| 斩道台 | Endgame | 旧天道核心 | 终局装备 |

## 材料链示例

飞剑线：

```text
木材 + 下品灵石 -> 木纹飞剑
木纹飞剑 + 器胚碎片 + 炉渣铁 -> 破云飞剑
破云飞剑 + 雷纹羽 + 劫云露 -> 雷纹剑匣
雷纹剑匣 + 宗门令 + 断剑残意 -> 无相剑轮
无相剑轮 + 月骸骨 + 斩道尘 -> 月骸法剑
```

炼丹线：

```text
灵草 + 下品灵石 -> 回春丹
回春丹 + 青木根 -> 凝气丹
凝气丹 + 药露 + Boss 材料 -> 筑基丹
筑基丹 + 劫云露 -> 抗劫丹
```

## 设计规则

- 新材料要回流到多个配方，避免一次性材料。
- 关键制作站必须来自 Boss 或明确探索目标。
- 终局材料不能过度依赖低概率刷怪。
