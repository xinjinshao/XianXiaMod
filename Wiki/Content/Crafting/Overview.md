## 关键配方链

飞剑线：
```
木材 + 下品灵石 → 木纹飞剑 → 破云飞剑 → 雷纹剑匣 → 无相剑轮 → 月骸法剑
```

炼丹线：
```
灵草 + 下品灵石 → 回春丹 → 凝气丹 → 筑基丹 → 抗劫丹
```

## 设计规则

- 新材料要回流到多个配方，避免一次性材料。
- 关键制作站必须来自 Boss 或明确探索目标。
- 终局材料不能过度依赖低概率刷怪。
