# 制作站分工

九种制作站现在各有实际配方职责。迁移只改变以下物品的制作站，不改变材料、产量、品质随机或已有装备。旧世界摆放的站点继续使用；旧装备无需重新制作。

| 制作站 | 当前主要职责 |
| --- | --- |
| 土炉 | 凝气丹，早期修行入口；工作台用黏土、石块和木材制作 |
| 符案 | 朱砂符火；工作台用木材和书制作 |
| 青木丹炉 | 筑基丹、回春丹、抗劫丹；保留早期恢复及抗劫供应 |
| 器胚炉 | 早期飞剑/符弩、青木阵盘、早期饰品、淬灵晶，以及雷锻台和试炼台的制作 |
| 星纹丹鼎 | 星蚀弩、星渊眼、觉醒印；用星蚀晶及狱石锭在青木丹炉制作 |
| 雷纹锻台 | 雷纹剑匣、雷符阵盘、鸣雷玉；材料来自雷系进度 |
| 宗门试炼台 | 无相剑轮、元婴玉匣；以宗门试炼令及器胚残片在器胚炉制作 |
| 天火炉 | 残天法旨、残天冠印；精金熔炉及天道碎片在秘银砧制作，亦用于制作斩道台 |
| 斩道台 | 月骸法剑、斩道戒、三路线奖励、道化印；同时作为路线选择及道化确认地点 |

材料获得先于对应工作台制作：试炼令来自无相剑魄，天道碎片来自天碑守御/残天监察使，斩道尘来自月骸仙君/旧天道核心。召唤物配方不随本批迁移；新站制作不要求已经拥有该站制造的武器。配方材料消耗仍有后续平衡空间。

这批共迁移13种现有配方，服务器构建、载入及声明检查通过；真实制作、原版工作台邻接、旧世界流程和完整通关仍需实机验收。未来高阶丹药、符箓与新增职业装备继续沿此分工接入。
