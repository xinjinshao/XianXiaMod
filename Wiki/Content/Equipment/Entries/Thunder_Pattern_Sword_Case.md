# 雷纹剑匣

[返回装备总览](../Overview.md)

## 定位

- 英文 ID：`thunder_pattern_sword_case`
- 阶段：Hardmode
- 类型：近战/灵气

## 数值

| 属性 | 值 |
|------|-----|
| 伤害 | 54 |
| 使用时间 | 22 |
| 击退 | 3 |
| 暴击 | 6% |
| 基础灵气消耗 | 未觉醒9；宗门传承7；显式觉醒6 |
| 射速 | 13 |
| 稀有度 | Light Red |

## 效果

- 释放穿透雷剑，命中NPC后有1/3概率触发小型雷击；雷击伤害为主雷剑当前伤害的一半向下取整，至少1，保留近战职业。

## 配方

器胚碎片×2 + 雷纹羽×12 + 下品灵石×12，在雷纹炉制作。

## 宗门传承与觉醒工艺

金丹境且宗门声望40时，独立宗门传承提供12%武器伤害，未觉醒基础灵耗由9降至7。

保有铭刻并淬炼三级、达到元婴境且击败青木药王残影后，可在支持的炼器站使用1枚法器觉醒印及24下品灵石显式觉醒。额外增加10%武器伤害，基础灵耗变为6；保留前缀、铭刻及淬炼状态。宗门传承的伤害条件独立计算，两项伤害增益按现有规则相加。

显式觉醒后开放“雷匣三落”：右键、主动技能热键或技能面板施放，在800像素范围内的可见目标上方240像素生成三道近战雷击，横向间隔96像素，以12速度下落，每道造成当前武器伤害的150%（向下取整，至少1）。基础灵耗30，共享冷却20秒；目标被墙遮挡、生成区或落雷路径受阻、容量不足及创建失败均不扣费或启动技能冷却。主人死亡、离线或权威端槽位更换时无伤并在至多6帧内退场。普通攻击仍可在共享技能冷却期间使用，觉醒基础灵耗6。实际费用受玩家倍率影响并向上取整。道化已于第259轮开放，详见下文。
