# 武器与饰品

[返回首页](../../Home.md)

## 武器分类

| 类型 | 对应职业 | 玩法定位 |
| --- | --- | --- |
| 飞剑 | 近战/魔法混合 | 召回、穿透、远程斩击 |
| 符箓 | 魔法/远程 | 一次性法术、状态效果 |
| 灵弩 | 远程 | 使用灵气弹药或符箭 |
| 阵盘 | 魔法/召唤 | 区域控制、持续效果 |
| 器灵 | 召唤 | 辅助攻击或防御 |
| 重器 | 近战 | 慢速高伤、破甲 |

## 示例武器

| 武器 | 阶段 | 类型 | 特点 |
| --- | --- | --- | --- |
| 木纹飞剑 | Pre-Boss | 飞剑 | 基础召回斩击 |
| 破云飞剑 | Pre-Hardmode | 飞剑 | 穿透云气弹 |
| 朱砂符火 | Pre-Hardmode | 符箓 | 点燃与短爆发 |
| 玄炉重锤 | Pre-Hardmode | 重器 | 高击退，低攻速 |
| 雷纹剑匣 | Hardmode | 飞剑 | 储存多把雷剑依次释放 |
| 星蚀弩机 | Hardmode | 灵弩 | 消耗星蚀晶产生分裂弹 |
| 无相剑轮 | Post-Plantera | 飞剑 | 依据移动方向变招 |
| 天碑镇印 | Post-Golem | 阵盘 | 区域压制与防御 |
| 月骸法剑 | Post-Moon Lord | 飞剑 | 混合月骸和星灾伤害 |

## 饰品分类

| 饰品 | 阶段 | 功能 |
| --- | --- | --- |
| 聚气坠 | Pre-Boss | 提高灵气恢复 |
| 灵木护符 | Pre-Hardmode | 小幅生命恢复 |
| 炉心戒 | Pre-Hardmode | 提高炼器武器伤害 |
| 避雷玉佩 | Hardmode | 降低天劫伤害 |
| 星渊眼 | Hardmode | 提升禁术伤害但增加灵压 |
| 元婴玉匣 | Post-Plantera | 强化召唤/分身机制 |
| 残天冠印 | Post-Golem | 强化天道系法宝 |
| 斩道环 | Endgame | 终局路线饰品 |

## 设计规则

- 每个进度段每个主要职业至少有 1 到 2 个可用选项。
- 饰品提供机制差异，不只堆伤害。
- 高风险饰品必须明确显示副作用。
