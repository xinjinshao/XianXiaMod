# 专家宝藏袋与专属饰品

12 个 Boss 使用 tModLoader 原生宝藏袋规则；专家/大师模式中符合引擎参与条件的玩家获得独立袋子，普通模式仍直接掉材料。袋中保留原材料及稀有奖励的数量、概率，并保证一件对应专家饰品。实际多人参与资格、开袋与库存表现尚需双客户端实测。

饰品均研究 1 件，宝藏袋研究 3 件。饰品没有制作配方，来源为对应宝藏袋；已获得的专家饰品可带入普通世界并使用。同一款的多份不会叠加，不同款可组合；效果只在功能饰品槽生效，隐藏外观不禁用属性。所有数值为首轮实现，战斗平衡仍待验收。

| Boss | 专家饰品 | 效果 |
| --- | --- | --- |
| 灵脉蠕虫 | 灵脉盘环 | 灵气恢复每周期增加1，防御增加2 |
| 药宗守园人 | 药园生息符 | 生命恢复每秒增加1，免疫中毒 |
| 玄炉铁傀 | 玄炉隔火印 | 防御增加6，免疫着火 |
| 劫云化身 | 劫雷导灵环 | 灵气消耗降低8%，受到的伤害降低3% |
| 雷泽蛟 | 蛟雷踏云佩 | 移动速度增加12%，跳跃速度增加1.5 |
| 星渊胎主 | 星渊聚灵镜 | 灵气恢复每周期增加2，魔法伤害增加6% |
| 无相剑魄 | 无相剑徽 | 近战伤害增加8%，近战护甲穿透增加8 |
| 青木药王残影 | 药王养生印 | 生命恢复每秒增加2，灵气恢复每周期增加1 |
| 天碑守御 | 天碑御守 | 受到的伤害降低6%，免疫击退 |
| 残天监察使 | 监察箭印 | 远程伤害增加8%，远程护甲穿透增加8 |
| 月骸仙君 | 月骸器灵契 | 召唤栏增加1，召唤伤害增加8% |
| 旧天道核心 | 旧天共鸣核 | 伤害增加10%，防御增加6，灵气恢复每周期增加2 |

灵气恢复周期沿用修行系统，不是每秒固定恢复；生命恢复采用原版 lifeRegen，+2 对应每秒增加 1 点基础恢复。免疫着火不代表免疫熔岩，移动加成遵循原版移动速度结算。

大师模式下每只Boss保证额外直接掉落一件对应大师纪念碑，属于世界共享掉落；宝藏袋和专家饰品仍沿用原规则。纪念碑可放置为2×3物件，要求两格有效地面支撑，拆除返还对应物品，无战斗加成；可带入普通世界放置，研究数量1，熔岩不摧毁。实际放置/拆除/多人拾取仍需图形客户端验证。纪念碑暂时复用本项目32×48剑碑素材（无帧间距），12种以物品名称和地图名称区分；袋子和饰品暂时复用本项目原创图标，独立素材仍在 T49 待办。
