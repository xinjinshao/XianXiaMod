# NPC 服务指引

五位NPC的每个进度对话都会附上对应服务操作说明，支持中英文。商店仍使用原生价格与购买流程，物品提示和工具确认界面提供实际材料、费用与限制。

| NPC | 入口与服务 |
| --- | --- |
| 药宗学徒 | 商店购买丹药、灵草种子和宗门玉简；种植成熟收获，丹炉制作丹药；使用玉简查看当前突破与主线目标 |
| 云游炼器师 | 购买铭针/祛纹石；在器胚炉等炼器站附近使用工具，选择背包目标并确认。淬灵晶、法器觉醒印与法器道化印使用相同目标选择入口，具体门槛按工具提示 |
| 观劫人 | 购买观劫盘读取灵压/天劫，天劫训练令用于失败后的合法重试；不会替玩家跳过当前天劫或再次收取突破材料 |
| 经阁卷灵 | 宗门玉简提供下一步目标和委托；器灵坠/契约需要手持使用才能召唤，佩戴加成另算，取消对应增益可结束召唤 |
| 坠天信使 | 天庭路线提示提供线索；击败旧天道核心取得路线材料，在斩道台附近使用材料并在界面确认世界路线；确认前查看效果与费用 |

NPC对话的商店与委托按钮保持原作用；服务通过实际物品/制作站进入。药宗学徒新增宗门玉简上架，避免必须先找到后期经阁NPC才能购买主线指南。坠天信使商店重复的天道碎片条目已移除。

当前已验证构建、本地化键与专服加载；五位NPC在不同玩家境界下的实际对话排版、工具UI操作、双客户端拒绝反馈和完整首次通关仍待实机验收。
