# 生态敌怪进度

自然生成同时检查生态条件与世界进度，原有生成权重不变。生态在新世界出现不再自动开放其后期敌怪。

| 解锁阶段 | 敌怪 |
| --- | --- |
| 开局 | 游灵史莱姆、碎玉蠕虫、符蝠、药园藤灵、瘴花蛾、铁屑灵、炉灰傀儡 |
| 困难模式 | 雷纹鹰、劫云灵、星渊幼体、星蚀修士 |
| 世纪之花后 | 执念剑修、经阁回响 |
| 石巨人后 | 天碑卫、仙傀 |
| 月亮领主后 | 月骸修士、归档仙魂 |

后续阶段同时要求前面的世界标志，异常存档中单独出现后期标志不会提前解锁。规则属于世界，加入已推进的世界的新角色仍会遇到该世界阶段的敌怪。未配置的新敌怪默认不能自然生成，须先补进度映射。

本批仅限制自然生成入口，保留生态要求、权重、数值和掉落；不清除既有NPC，不改变Boss脚本召唤。后期自然敌怪及其掉落随进度开放。Boss召唤仍使用独立的境界/世界前置检查。

17种敌怪的全部16组合进度标志已通过政策回归（含不一致存档），并检查实际SpawnChance接入。真实新世界刷怪、各阶段掉落及多人场景仍待实机验收；生态资源方块的采掘门槛另属探索与资源任务。
